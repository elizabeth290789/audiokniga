# Аудиокнига для Android

Читалка импортирует EPUB, FB2 и TXT с телефона и озвучивает извлечённый текст системными голосами Android. Доступны русский и английский языки, скорость от 0,5× до 2× и перемотка по тексту. Для каждой книги сохраняются язык и позиция. Фоновым чтением можно управлять из уведомления и через системные медиакнопки.

## Установка

[Скачать APK](https://github.com/elizabeth290789/audiokniga/raw/refs/heads/main/apk/audiokniga-debug.apk) для Android 8.0 и новее. Это тестовая сборка для установки на телефон.

## Сборка

Нужны JDK 17 или 21, Android SDK Platform 35 и Android SDK Build Tools 35.0.0. Укажите путь к Android SDK через `ANDROID_HOME` или `sdk.dir` в локальном файле `local.properties`.

```sh
./gradlew :app:assembleDebug :app:lintDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Его можно установить на устройство с Android 8.0 или новее через Android Studio или командой `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

## Как слушать

1. Нажмите «+ Книга» и выберите файл EPUB, FB2 или TXT. Формат определяется по расширению файла.
2. Выберите книгу. Если приложение неверно определило язык, переключите его кнопкой «РУ» или «EN». Нажмите «Голос», чтобы прослушать доступные варианты и выбрать голос для книги.
3. Нажмите «Слушать» или откройте «Текст книги», чтобы читать и слушать одновременно. Текущий фрагмент подсвечивается. Стрелки листают страницы, а нажатие на номер страницы открывает поле для перехода по номеру.
4. Для фонового чтения сверните приложение или заблокируйте экран. Пауза и продолжение доступны через системный медиаплеер.

Приложение разбивает извлечённый текст на страницы длиной до 1800 знаков. Номера сохраняются при повороте экрана и изменении размера шрифта. Они относятся к тексту в приложении и могут отличаться от нумерации в другом издании.

Доступные варианты в меню «Голос» зависят от установленного движка и его офлайн-голосов. Для другого русского произношения сравните образцы или установите дополнительный русский голос в системных настройках синтеза речи Android. Движок расставляет ударения сам, поэтому результат может меняться от голоса к голосу. Если движок не сообщает точную позицию слова, приложение подсвечивает весь текущий фрагмент.

Импортированный текст и позиция хранятся на телефоне. Точность продолжения зависит от системного голоса: если движок не сообщает текущую позицию внутри фразы, приложение продолжает с начала текущего фрагмента. Иллюстрации и явно размеченные подписи пропускаются. Если подпись оформлена обычным абзацем, она читается вместе с остальным текстом. EPUB с DRM, PDF и экспорт аудио не поддерживаются.
